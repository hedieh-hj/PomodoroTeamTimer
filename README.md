# Pomodoro Team Timer

تایمر پومودوروی همگام برای تیم‌ها، قابل اجرا در شبکهٔ داخلی و بدون وابستگی به اینترنت.

## اجرا

پیش‌نیاز: .NET 7 SDK روی سیستم میزبان.

```powershell
dotnet run --project PomodoroTeamTimer.Server
```

سپس روی سیستم میزبان `http://localhost:5080` را باز کنید. اعضای تیم با آدرس
`http://IP-میزبان:5080` وارد می‌شوند. برای پیدا کردن IP در ویندوز از `ipconfig` استفاده کنید.

برای اجرا در System Tray ابتدا solution را build و سپس launcher را اجرا کنید:

```powershell
dotnet build PomodoroTeamTimer.sln
.\PomodoroTeamTimer.Tray\bin\Debug\net7.0-windows\PomodoroTeamTimer.Tray.exe
```

اگر Windows Firewall سؤال کرد، دسترسی شبکه‌های Private را فعال کنید. منوی tray آدرس LAN را نمایش می‌دهد و با کلیک روی آن، آدرس کپی می‌شود.

## قابلیت‌ها

- ساخت و ورود به اتاق با کد شش‌رقمی
- تایمر مرجع سمت سرور با همگام‌سازی زنده SignalR
- شروع، توقف، ادامه، ریست، پایان و ردکردن استراحت توسط میزبان
- وضعیت آنلاین اعضا با heartbeat
- صدای هشدار و اعلان سیستم در مرورگرهای پشتیبانی‌شده
- ذخیرهٔ محلی تاریخچه و آمار روزانه در `PomodoroTeamTimer.Server/App_Data`
- رابط فارسی RTL، واکنش‌گرا و قابل نصب به‌صورت PWA
- اجرای میزبان در System Tray ویندوز

## معماری

سرور ASP.NET Core هم فایل‌های رابط وب و هم Hub زنده را ارائه می‌کند. زمان پایان هر فاز روی سرور ثبت می‌شود؛ بنابراین refresh صفحه، خواب سیستم یا تأخیر کوتاه شبکه باعث اختلاف تایمر کاربران نمی‌شود. ذخیره‌سازی JSON اتمیک است و هیچ دیتابیس یا سرویس خارجی لازم ندارد.
